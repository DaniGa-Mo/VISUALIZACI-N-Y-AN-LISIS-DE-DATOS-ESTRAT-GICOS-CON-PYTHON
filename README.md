## 🧠 Descripción del Proyecto

Este proyecto consiste en el análisis exploratorio de datos (EDA) y la construcción de un dashboard estratégico utilizando Python, con el objetivo de obtener insights clave sobre el rendimiento de ventas de un supermercado.

El enfoque principal fue transformar datos en información visual clara, apoyando la toma de decisiones comerciales mediante un dashboard intuitivo y coherente.

---

## 🎯 Objetivos

- Analizar la rentabilidad por categoría de productos  
- Evaluar la distribución de ventas según horario  
- Examinar la satisfacción de clientes mediante ratings  
- Identificar posibles relaciones entre monto de compra y satisfacción  

---

## 📊 Dashboard

El dashboard está compuesto por 4 visualizaciones principales:

### 🟢 1. Rentabilidad por Categoría
- Gráfico de barras horizontales con gradiente
- Permite identificar las categorías más rentables

### 🟡 2. Distribución de Ventas por Horario
- Gráfico de torta (pie chart)
- Compara ventas entre mañana y tarde

### 🟡 3. Distribución de Ratings
- Histograma
- Muestra la frecuencia de satisfacción de clientes

### 🟢 4. Relación Monto vs Rating
- Gráfico de dispersión (scatter plot)
- Analiza la correlación entre gasto y satisfacción

---

## 🔍 Insights Clave

- Las categorías **Food and Beverages** y **Sports and Travel** generan mayores ingresos  
- Existe una ligera mayor concentración de ventas en horario de **tarde**  
- El rating promedio de los clientes es aproximadamente **6.97**  
- **No se observa una relación directa entre el monto de compra y la satisfacción del cliente**
